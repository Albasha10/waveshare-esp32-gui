Efficiency Formula
How Efficiency is worked out. The board calculates it, so the Dashboard, the cards and the SD-card log all use this formula. Result in %.
Names: runtime, downtime, total (= runtime + downtime), cycle (last cycle) — in seconds; parts, rejects, good (= parts − rejects); [AnalogIn1] = a PLC value. Use + - * / ( ) and numbers. For OEE replace IDEAL with the ideal cycle time in seconds (e.g. 2.5).
